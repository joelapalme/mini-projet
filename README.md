# Mini-projet d'apprentissage

Mon tout premier projet GitHub, créé pour apprendre les bases de Git, GitHub et le développement web.

## À propos

Ce projet a été réalisé dans le cadre de mon apprentissage du développement web moderne, en préparation de la création du site **Jump&Love**.

## Technologies utilisées

- HTML5
- CSS3
- Git & GitHub

## Ce que j'ai appris

- ✅ Utiliser le Terminal (`pwd`, `ls`, `cd`, `mkdir`)
- ✅ Versionner du code avec Git (`add`, `commit`, `push`)
- ✅ Publier sur GitHub
- ✅ Lire l'historique (`git log --oneline`, alias `git lg`)
- ✅ Ignorer des fichiers avec `.gitignore`
- ✅ Annuler des erreurs (`git restore`, `git reset`)
- ✅ Écrire en Markdown
